## 请求类型详解

> **大结果处理**：当响应数据超过 300 个字符时，自动写入独立的 `result_{requestId}.json` 文件，`result.json` 中只保留 `requestId`、`success`、`hasLongResult: true`、`longResultFile` 等简要字段。外部程序根据 `longResultFile` 读取完整结果。

### 1. 场景层级查询 `scene_hierarchy`

查询 Unity 场景中的 GameObject 层级结构。

**请求：**
```json
{
    "requestId": "scene_001",
    "type": "scene_hierarchy",
    "params": {
        "rootType": "all_canvases"
    }
}
```

| 参数       | 类型   | 必填                    | 说明                                                              |
| ---------- | ------ | ----------------------- | ----------------------------------------------------------------- |
| `rootType` | string | 否                      | `"all_canvases"`（列出所有Canvas，默认）或 `"path"`（按路径查询） |
| `path`     | string | 当rootType="path"时必填 | 路径，如 `"Canvas/CharacterMenu/..."`                             |

**响应示例：**
```json
{
    "requestId": "scene_001",
    "success": true,
    "data": [
        {
            "name": "Canvas",
            "active": true,
            "path": "Canvas",
            "components": ["Canvas", "CanvasScaler", "GraphicRaycaster"],
            "localPosition": {"x": 0, "y": 0, "z": 0},
            "childCount": 5,
            "children": [
                {
                    "name": "MainMenu",
                    "active": true,
                    "path": "Canvas/MainMenu",
                    "components": ["RectTransform", "Image", "Button"],
                    "localPosition": {"x": 0, "y": 100, "z": 0},
                    "childCount": 3,
                    "children": [ ... ]
                }
            ]
        }
    ]
}
```

> 层级递归深度默认为 5 层，超出部分以 `childrenTruncated: true` 标记。

### 2. 组件信息查询 `component_info`

查询某 GameObject 上挂载的组件列表及其公开字段。

**请求：**
```json
{
    "requestId": "comp_001",
    "type": "component_info",
    "params": {
        "gameObjectPath": "Canvas/CharacterMenu/EquipPanel",
        "componentType": "Button"
    }
}
```

| 参数             | 类型   | 必填 | 说明                                                   |
| ---------------- | ------ | ---- | ------------------------------------------------------ |
| `gameObjectPath` | string | 是   | GameObject 的完整路径（从场景根开始）                  |
| `componentType`  | string | 否   | 筛选组件类型（按类名，忽略大小写），不填则返回所有组件 |

**响应示例：**
```json
{
    "requestId": "comp_001",
    "success": true,
    "data": [
        {
            "type": "UnityEngine.UI.Button",
            "typeName": "Button",
            "fields": {
                "interactable": true,
                "targetGraphic": {"_type": "...Graphic", "_id": 123},
                "transition": 1,
                "colors": {"normalColor": {"r": 1, "g": 1, "b": 1, "a": 1}}
            }
        }
    ]
}
```

### 3. 组件字段查询 `component_field`

查询某组件的特定字段值。

**请求：**
```json
{
    "requestId": "field_001",
    "type": "component_field",
    "params": {
        "gameObjectPath": "Canvas/CharacterMenu/EquipPanel",
        "componentType": "RectTransform",
        "field": "sizeDelta"
    }
}
```

| 参数             | 类型   | 必填 | 说明                  |
| ---------------- | ------ | ---- | --------------------- |
| `gameObjectPath` | string | 是   | GameObject 的完整路径 |
| `componentType`  | string | 是   | 组件类型名            |
| `field`          | string | 是   | 字段名或属性名        |

**响应示例：**
```json
{
    "requestId": "field_001",
    "success": true,
    "data": {
        "type": "UnityEngine.RectTransform",
        "componentType": "RectTransform",
        "field": "sizeDelta",
        "value": {"x": 800, "y": 600}
    }
}
```

### 4. 通用数据查询 `game_data`

通过 `DomainManager` 查询任意游戏数据域的字段或调用方法。支持链式调用：域方法 → 对象方法 → 读字段。

**请求：**
```json
{
    "requestId": "data_001",
    "type": "game_data",
    "params": {
        "domain": "Character",
        "method": "GetElement_Objects",
        "args": [10001],
        "objectMethods": ["GetFullName"],
        "field": "Surname"
    }
}
```

| 参数           | 类型   | 必填 | 说明                                           |
| -------------- | ------ | ---- | ---------------------------------------------- |
| `domain`       | string | 是   | 数据域名称，可选值见下方                       |
| `method`       | string | 否   | 要调用的域方法名                               |
| `args`         | array  | 否   | 域方法参数数组                                 |
| `objectMethods` | array | 否   | 链式方法名数组，如 `["GetFullName", "GetSurname"]` |
| `objectArgsList` | array | 否   | 与 `objectMethods` 对应的参数列表              |
| `field`        | string | 否   | 要读取的字段名（从最后的结果对象中读取）       |

**执行流程：**
```
domain.method(args) → 对象 A
  → A.objectMethods[0](argsList[0]) → 对象 B
    → A.objectMethods[1](argsList[1]) → 对象 C
      → (可选) 读取 field → 最终值
```

**可用域（Domain）列表：**

| 域名           | 说明         | 域ID |
| -------------- | ------------ | ---- |
| `World`        | 世界数据     | 1    |
| `Map`          | 地图数据     | 2    |
| `Organization` | 组织数据     | 3    |
| `Character`    | 角色数据     | 4    |
| `Taiwu`        | 太吾数据     | 5    |
| `Item`         | 物品数据     | 6    |
| `CombatSkill`  | 战斗技能数据 | 7    |
| `Combat`       | 战斗数据     | 8    |
| `Building`     | 建筑数据     | 9    |
| `Adventure`    | 冒险数据     | 10   |
| `Merchant`     | 商人数据     | 14   |
| `Extra`        | 扩展数据     | 19   |

**使用示例：**

调用域方法并读取返回字段：
```json
{"type": "game_data", "params": {"domain": "Character", "method": "GetNameRelatedData", "args": [10001], "field": "FullName"}}
```

获取角色对象并调用实例方法（单级）：
```json
{"type": "game_data", "params": {"domain": "Character", "method": "GetElement_Objects", "args": [10001], "objectMethods": ["GetFullName"]}}
```

多级链式调用：
```json
{"type": "game_data", "params": {"domain": "Character", "method": "GetElement_Objects", "args": [10001], "objectMethods": ["GetFullName", "GetSurname"]}}
```

多级链式+读字段：
```json
{"type": "game_data", "params": {"domain": "Character", "method": "GetElement_Objects", "args": [10001], "objectMethods": ["GetFullName"], "field": "Surname"}}
```

**进阶特性（前后端均支持）：**

- **泛型方法调用** — `objectMethods` 方法名支持 `<类型名>` 语法，如 `"GetComponent<RectTransform>"` 或 `"GetInstance<SomeType>"`，系统自动解析泛型类型并调用 `MakeGenericMethod`。
- **枚举参数自动转换** — 当方法参数为枚举类型时可直接传 `int` 值（JSON 中写数字即可），自动 `Enum.ToObject` 转换。例如方法签名 `SetType(MyEnum e)`，传 `"args": [0]` 等价于 `SetType(MyEnum.None)`。
- **数字类型兼容** — `int`↔`long`↔`float`↔`double` 自动提升/降级。

链式调用 + 泛型 + 枚举参数示例：
```json
{
    "type": "game_data",
    "params": {
        "domain": "Character",
        "method": "GetElement_Objects",
        "args": [10001],
        "objectMethods": ["GetComponent<RectTransform>"],
        "field": "anchoredPosition"
    }
}
```

查询太吾的当前日期：
```json
{"type": "game_data", "params": {"domain": "World", "method": "GetCurrDate"}}
```

查询域概览（列出域中所有简单类型的字段）：
```json
{"type": "game_data", "params": {"domain": "Taiwu"}}
```

### 6. 角色信息查询 `character_info`

查询指定角色的详细信息。

**请求：**
```json
{
    "requestId": "char_001",
    "type": "character_info",
    "params": {
        "charId": 10001
    }
}
```

**响应：** 返回角色的所有字段（通过 Traverse 反射读取，深度限制 3 层），包含 `_type` 类型信息和 `_id` 标识。

### 7. 世界信息查询 `world_info`

查询当前游戏世界的日期和状态。

**请求：**
```json
{
    "requestId": "world_001",
    "type": "world_info"
}
```

**响应示例：**
```json
{
    "requestId": "world_001",
    "success": true,
    "data": {
        "currDate": 240,
        "year": 20,
        "month": 1,
        "worldId": 12345678,
        "isFinishedInit": true
    }
}
```

> `currDate` 是游戏内部月份计数（从0开始），`year = currDate / 12`，`month = currDate % 12 + 1`。

### 8. 角色姓名查询 `character_name`

使用 `CharacterDomain` 专用 API 获取角色姓名，比 `game_data` 方式更直接。

**请求：**
```json
{
    "requestId": "cname_001",
    "type": "character_name",
    "params": {
        "charId": 10001
    }
}
```

| 参数     | 类型 | 必填 | 说明               |
| -------- | ---- | ---- | ------------------ |
| `charId` | int  | 是   | 角色ID             |

**响应示例：**
```json
{
    "requestId": "cname_001",
    "success": true,
    "data": {
        "charId": 10001,
        "surname": "张",
        "givenName": "三",
        "fullName": "张三"
    }
}
```

> 内部通过 `CharacterDomain.GetNameRelatedData(charId)` 和 `CharacterDomain.GetRealName(character)` 两个 API 互补获取。

### 9. 前端数据查询 `frontend_data`

查询前端可直接访问的游戏数据（不走后端）。
通用实现：`data` 参数为类名，通过 `SingletonObject.getInstance&lt;T&gt;()` 获取实例，支持链式调用和读字段。
支持任意注册为 Singleton 的类型，如 `BasicGameData`、`CharacterMonitorModel` 等。

**请求示例 — 查询特定字段：**
```json
{
    "requestId": "fe_001",
    "type": "frontend_data",
    "params": {
        "data": "BasicGameData",
        "field": "TaiwuCharId"
    }
}
```

**请求示例 — 查询所有字段：**
```json
{
    "requestId": "fe_002",
    "type": "frontend_data",
    "params": {
        "data": "BasicGameData"
    }
}
```

**请求示例 — 链式调用 + 读字段：**
```json
{
    "requestId": "fe_003",
    "type": "frontend_data",
    "params": {
        "data": "BasicGameData",
        "objectMethods": ["GetType"],
        "field": "Name"
    }
}
```

| 参数           | 类型   | 必填 | 说明                                           |
| -------------- | ------ | ---- | ---------------------------------------------- |
| `data`         | string | 是   | 类名（如 `BasicGameData`、`CharacterMonitorModel`） |
| `objectMethods` | array | 否   | 链式方法名数组，同 `game_data`                    |
| `objectArgsList`| array | 否   | 方法参数列表，同 `game_data`                      |
| `field`        | string | 否   | 具体字段名，不填则返回所有公开字段（大数据量会自动拆分） |

**执行流程：**
```
SingletonObject.getInstance<T>() → 实例
  → objectMethods[0](argsList[0]) → 对象 B
    → (可选) 读取 field → 最终值
```

**响应示例：**
```json
{
    "requestId": "fe_001",
    "success": true,
    "data": {
        "_type": "BasicGameData",
        "field": "TaiwuCharId",
        "value": 10001
    }
}
```

> `frontend_data` 由前端插件直接处理，不经过后端通讯。`data` 参数可以是任意注册为 Singleton 的类型名，前端通过 `SingletonObject.getInstance&lt;T&gt;()` 获取实例后执行链式调用或读取字段。
