# 1. 查询场景 Canvas 列表

**需求：** 查看当前游戏场景中有多少个 Canvas、路径分组

**请求（1次）：**

```json
{
    "requestId": "scene_canvases_001",
    "type": "scene_hierarchy",
    "params": {
        "rootType": "all_canvases"
    }
}
```

| 参数 | 值 | 说明 |
|:----|:---|:-----|
| `rootType` | `"all_canvases"` | 列出所有 Canvas |

**预期返回关键数据：**

```json
{
    "requestId": "scene_canvases_001",
    "success": true,
    "hasLongResult": true,
    "longResultFile": "result_scene_canvases_001.json"
}
```

从 `longResultFile` 中解析：

- 顶层数组每个元素是一个 Canvas 节点
- 每个节点含：`name`, `active`, `path`, `components[]`, `childCount`, `children[]`（递归深度 5 层）
- 通过分析 `path` 前缀可统计各摄像机下的 Canvas 数量

**关键路径提取命令 (PowerShell)：**

```powershell
# 统计 Canvas
$json | ForEach-Object { $_.name }
# 按路径前缀分组
$json | Group-Object { if ($_.path -match '^(.+?)/') { $matches[1] } else { 'RootLevel' } }
```

# 2. 查询 UI 面板状态和子物体

**需求：** 查询某个具体的 UI 面板（如 ViewBottom）是否显示，及其一级子物体列表

**请求（1次）：**

```json
{
    "requestId": "scene_viewbottom_002",
    "type": "scene_hierarchy",
    "params": {
        "rootType": "path",
        "path": "Camera_UIRoot/Canvas/LayerPart/ViewBottom"
    }
}
```

| 参数 | 值 | 说明 |
|:----|:---|:-----|
| `rootType` | `"path"` | 按路径查询 |
| `path` | 完整 GameObject 路径 | 从场景根开始 |

**预期返回关键数据（result 或 longResultFile）：**

```json
{
    "name": "ViewBottom",
    "active": true,
    "path": "Camera_UIRoot/Canvas/LayerPart/ViewBottom",
    "components": ["RectTransform", "Canvas", "ViewBottom", "ReadAndLoop", ...],
    "childCount": 3,
    "children": [
        { "name": "AnimationRoot", "active": true, "childCount": 26 },
        { "name": "CustomButtonPrefab", "active": false, "childCount": 1 },
        { "name": "Mask", "active": false, "childCount": 3 }
    ]
}
```

**关键字段：**

| 字段 | 说明 |
|:----|:-----|
| `active` | 是否显示（true/false） |
| `childCount` | 子物体数量 |
| `children[].name` | 子物体名称 |
| `children[].active` | 子物体是否显示 |
| `components[]` | 组件列表 |

# 3. 查找 UI 面板中的按钮

**需求：** 从已获取的层级数据中，找到所有按钮（Button/CButton/CustomButton）及其激活状态

**过程：** 使用前一请求返回的 `longResultFile` 数据，进行递归搜索

**提取命令 (PowerShell)：**

```powershell
function Find-Buttons($node, $depth=0) {
    $indent = '  ' * $depth
    if ($node.name -match '[Bb]utton' -or
        ($node.components | Where-Object { $_ -match '[Bb]utton' })) {
        Write-Host "${indent}[$compActual] $($node.name) active=$($node.active) path=$($node.path)"
    }
    if ($node.children) { foreach ($child in $node.children) { Find-Buttons $child ($depth+1) } }
}
Find-Buttons $json
```

**预期输出示例：**

```
[Button] MainCharacterButton active=True path=.../MainCharacterButton
[CButton] OpenCharMenu active=True path=.../OpenCharMenu
[CButton] Teammate1 active=True path=.../Teammate1
[CButton] WorldMap active=True path=.../MapButton/WorldMap
[CButton] MapFilter active=True path=.../MapButton/MapFilter
...
```

**匹配规则：** 节点名或组件名包含 `"Button"`（忽略大小写）

# 4. 查询 Spine 动态立绘信息

**需求：** 查询 NpcSpine 的骨骼名、皮肤、动画、缩放、纹理等信息

**步骤：** 多次 `component_info` / `component_field` 请求

| 步骤 | 请求类型 | 参数 | 预期结果 |
|:----|:--------|:-----|:---------|
| 4.1 查组件概况 | `component_info` | `gameObjectPath: ".../NpcSpine"`, `componentType: "SkeletonGraphic"` | 基础字段：`startingAnimation: "Loop"`, `timeScale: 1.0` |
| 4.2 查当前动画 | `component_field` | `componentType: "SkeletonGraphic"`, `field: "AnimationState"` | `_toString: "Loop"` |
| 4.3 查骨骼数据资产 | `component_field` | `componentType: "SkeletonGraphic"`, `field: "skeletonDataAsset"` | `_type: "SkeletonDataAsset"` |
| 4.4 查所属 Avatar | `component_info` | `gameObjectPath: ".../MainCharacterButton"`, `componentType: "Avatar"` | `PreferDynamicAvatar: true`, `Size: "Normal"` |
| 4.5 查骨骼资源名 | `component_field` | `componentType: "Avatar"`, `field: "_currentSpineName"` | `"Yj:vivian"` |
| 4.6 查皮肤 | `component_field` | `componentType: "Avatar"`, `field: "_currentSpineSkin"` | `""`（空=默认皮肤） |
| 4.7 查纹理 | `component_field` | `componentType: "SkeletonGraphic"`, `field: "mainTexture"` | `_toString: "vivian (Texture2D)"` |

**完整请求参数 (4.5)：**

```json
{
    "requestId": "field_spinename_009",
    "type": "component_field",
    "params": {
        "gameObjectPath": "Camera_UIRoot/Canvas/LayerPart/ViewBottom/AnimationRoot/MainCharacterButton",
        "componentType": "Avatar",
        "field": "_currentSpineName"
    }
}
```

**预期汇总：**

| 字段 | 示例值 | 说明 |
|:----|:------|:-----|
| `_currentSpineName` | `"Yj:vivian"` | Spine 骨骼资源名 |
| `_currentSpineSkin` | `""` | 默认皮肤（空字符串） |
| `mainTexture` | `"vivian"` | 主纹理名 |
| 当前动画 | `"Loop"` | 循环待机动画 |
| `timeScale` | `1.0` | 正常速度 |

# 5. 查询太吾姓名

**需求：** 获取太吾角色的姓名。有三种途径，推荐途径 1。

### 途径 1：`taiwu_info`（推荐，最快捷）

```json
{
    "requestId": "taiwu_001",
    "type": "taiwu_info"
}
```

**预期：**

```json
{
    "taiwuCharId": 6755,
    "taiwuCharacter": { "name": "竺梦堂", "age": 18, "gender": 1 }
}
```

### 途径 2：`character_name`

```json
{
    "requestId": "cname_001",
    "type": "character_name",
    "params": { "charId": 6755 }
}
```

**预期：**

```json
{ "surname": "竺", "givenName": "梦堂", "fullName": "竺梦堂" }
```

### 途径 3：`game_data` + `GetNameRelatedData`

```json
{
    "requestId": "data_001",
    "type": "game_data",
    "params": {
        "domain": "Character",
        "method": "GetNameRelatedData",
        "args": [6755],
        "field": "FullName"
    }
}
```

**预期：** `FullName` 结构体，含 `customSurnameId`、`customGivenNameId`，对照 `CustomTexts` 得到文本

### 途径 4：`frontend_data` + `BasicGameData`

```json
{
    "requestId": "fe_001",
    "type": "frontend_data",
    "params": { "data": "BasicGameData", "field": "CustomTexts" }
}
```

**预期：** `CustomTexts{0:"竺", 1:"梦堂", ...}`

# 8. 查询角色魅力值（后端）

**需求：** 通过后端 API 获取角色的魅力值

**步骤：**

| 步骤 | 请求 | 说明 |
|:----|:-----|:-----|
| 8.1 查到同道 ID 列表 | 见 #7 | 获取 charIds |
| 8.2 查询姓名 | `character_name` | 确认角色 |
| 8.3 查魅力值 | `game_data` + `objectMethods` | 详见下方 |

**请求（8.3）：**

```json
{
    "requestId": "charm_001",
    "type": "game_data",
    "params": {
        "domain": "Character",
        "method": "GetElement_Objects",
        "args": [7059],
        "objectMethods": ["CalcAttraction"]
    }
}
```

**说明：** `GetElement_Objects(charId)` 获取角色对象 → `CalcAttraction()` 调用角色的私有方法计算魅力值

**预期：** `900`（int，魅力值）

# 9. 查询角色魅力值（前端）

**需求：** 通过前端 `CharacterMonitorModel` 获取角色的魅力值

**步骤：**

| 步骤 | 请求 | 说明 |
|:----|:-----|:-----|
| 9.1 查到同道 ID 列表 | 见 #7 途径 2 | 获取 charIds |
| 9.2 查魅力值 | `frontend_data` + `GetMonitorItem<T>` + `field` | 详见下方 |

**请求：**

```json
{
    "requestId": "fe_charm_001",
    "type": "frontend_data",
    "params": {
        "data": "CharacterMonitorModel",
        "objectMethods": ["GetMonitorItem<CharacterDataMonitor.DetailInfoMonitor>"],
        "objectArgsList": [[7059, false]],
        "field": "Attraction"
    }
}
```

**参数说明：**

| 参数 | 值 | 说明 |
|:----|:---|:-----|
| `data` | `"CharacterMonitorModel"` | 前端单例类名 |
| `objectMethods` | `["GetMonitorItem<...>"]` | 泛型方法格式：`MethodName<TypeFullName>` |
| `objectArgsList` | `[[charId, false]]` | 参数列表，bool 参数用 JSON `false` |
| `field` | `"Attraction"` | 从返回对象中读取的属性名 |

**可用的 Monitor 类型：**

| Monitor 类型 | 关键属性 | 用途 |
|:-----------|:---------|:-----|
| `DetailInfoMonitor` | `Attraction`, `Fame`, `Happiness` | 魅力、名声、心情 |
| `BasicInfoMonitor` | `Gender`, `FavorabilityToTaiwu` | 性别、好感 |
| `AttributeMonitor` | `MaxMainAttribute`, `AtkHitValues` | 六维主属性、命中 |
| `AvatarInfoMonitor` | `AvatarData`, `AvatarAge` | 头像数据 |
| `AgeHealthMonitor` | — | 年龄健康 |
| `FeatureMonitor` | — | 特性 |

**预期：** `{ "field": "Attraction", "value": 900 }`

# 11. 查询角色详细信息

**需求：** 获取角色的完整字段数据

**请求（1次）：**

```json
{
    "requestId": "char_detail_001",
    "type": "character_info",
    "params": { "charId": 7059 }
}
```

**预期：** 返回 Character 对象的所有字段（深度 3 层），包括：

| 字段 | 说明 |
|:----|:-----|
| `templateId` | 角色模板 ID |
| `gender` | 性别（0=女, 1=男） |
| `actualAge` | 实际年龄 |
| `baseMainAttributes` | 基础六维属性 |
| `featureIds[]` | 特性 ID 列表 |
| `health` | 当前健康值 |
| `extraNeili` | 内力 |
| `consummateLevel` | 造诣等级 |
| `learnedLifeSkills[]` | 已学生活技能 |
| `learnedCombatSkills[]` | 已学战斗技能 |

> 数据量大时不会自动拆分到独立文件（当前后端处理逻辑）。
>
> **建议：** 如需特定字段，优先使用 `game_data` + `objectMethods` + `field` 进行精确定位。
