# 1. 前置条件

## 使用的工具

| 工具 | 用途 |
|:----|:-----|
| scene_hierarchy | 列举 Canvas / 按路径查询场景层级 |
| component_info | 查询 GameObject 上的组件及其字段 |
| component_field | 读取组件的特定字段值 |
| front_code | 反射链：查找对象、读字段、调用方法（含按钮点击） |
| simulate_click | 用 EventSystem 模拟指针点击，触发 IPointerClickHandler |
| shop_buy_filtered | 商店通用筛选购买，按 itemType/grade/name/pricePercent 等条件筛选商品 |

## 关键概念

- UI 按钮 = GameObject + Button 组件
- scene_hierarchy 探查得到按钮 path
- front_code 链式调用触发 Button.onClick.Invoke()

# 4. 游戏生命周期管理

## 4.1 启动游戏

> **注意：** 启动后建议等待 30~50 秒，直到 query_world_info() 返回数据再操作。游戏加载 Mod 并初始化约需 30~45 秒。

`powershell
start steam://rungameid/838350
`

## 4.2 确认运行状态

`powershell
Get-Process -Name "The Scroll Of Taiwu" -ErrorAction SilentlyContinue
`

或调用 query_world_info()

## 4.3 重启游戏

`powershell
taskkill /f /t /im "The Scroll of Taiwu.exe"
Start-Sleep -Seconds 3
start steam://rungameid/838350
`

## 4.4 退出游戏

| 界面 | 操作 | 路径 |
|:----|:-----|:-----|
| 游戏内 | UIElement.SystemOption.Show() → ExitGame | `.../ViewSystemOption/.../Content/ExitGame` |
| 主界面 | 直接点击 Button_7 "收起绘卷" | `.../MainMenu/Button_7` |
| 确认框 | 点击 BtnYes 确认退出 | `.../ViewDialog/AnimRoot/Buttons/BtnYes` |

# 5. 标准工作流

## 5.1 进入游戏

| 步骤 | 操作 | 工具 |
|:----|:-----|:-----|
| 1 | 确认游戏已启动 | Get-Process / query_world_info() |
| 2 | 判断是否在主界面 | query_taiwu_info() 成功→已进入；失败→主界面 |
| 3 | 点击展开绘卷 | front_code + onClick.Invoke() |
| 4 | 等待存档界面 | scene_hierarchy 轮询 |
| 5 | **选中目标存档** | simulate_click 通过 EventSystem 触发 IPointerClickHandler |
| 6 | **点击继续按钮** | front_code + ButtonContinue.onClick.Invoke() |
| 7 | 等待进入游戏 | 轮询 query_world_info() |
| 8 | 确认进入成功 | query_taiwu_info() 有数据 |
| 9 | **关闭月报**（如出现） | ViewMonthNotify/.../Close 的 Button.onClick.Invoke() |

## 5.2 返回主界面

| 步骤 | 操作 | 工具 |
|:----|:-----|:-----|
| 1 | 确认在游戏内 | query_taiwu_info() |
| 2 | 打开系统菜单 | front_code + `UIElement.SystemOption.Show()` |
| 3 | 等待菜单出现 | scene_hierarchy 检测 |
| 4 | 点击返回标题 | front_code + ReturnToMainMenu.onClick.Invoke() |
| 5 | 确认对话框 | front_code + BtnYes.onClick.Invoke() |
| 6 | 确认回到主界面 | query_taiwu_info() 超时或 currDate=0 |

# 6. 实战示例

## 6.1 主界面 → 展开绘卷

**已验证的按钮路径：**

| 元素 | 完整路径 |
|:----|:---------|
| 主界面 Canvas | `Camera_UIRoot/Canvas/LayerMain/ViewMainMenu` |
| 按钮列表容器 | `Camera_UIRoot/Canvas/LayerMain/ViewMainMenu/Root/MainMenu` |
| **展开绘卷** | `.../MainMenu/Button`（Text 标签：`"展开绘卷"`） |
| 太吾演武 | `.../MainMenu/Button_2`（Text 标签：`"太吾演武"`） |
| Button_3 ~ Button_7 | `.../MainMenu/Button_3` ~ `Button_7` |
| 子菜单组 | `.../MainMenu/SubMenu` |

**步骤：** 列举 Canvas → 读按钮标签 → 点击

```python
from ingame_helper import *

# 1. 列举 Canvas 确认主界面
query_scene_hierarchy(root_type="all_canvases")

# 2. 查看 MainMenu 按钮的标签文字，找到"展开绘卷"
base = "Camera_UIRoot/Canvas/LayerMain/ViewMainMenu/Root/MainMenu"
r = query_component_field(game_object_path=f"{base}/Button/Label",
    component_type="Text", field="text")
# → {"value": "展开绘卷"}

# 3. 验证按钮可点击
r = query_component_field(game_object_path=f"{base}/Button",
    component_type="Button", field="interactable")

# 4. 点击展开绘卷
r = front_code(entry_name="UnityEngine.GameObject", chain=[
    {"step": "method", "name": "Find", "argTypes": ["System.String"],
     "args": [f"{base}/Button"]},
    {"step": "method", "name": "GetComponent<UnityEngine.UI.Button>"},
    {"step": "property", "name": "onClick"},
    {"step": "method", "name": "Invoke"}
])
# → 返回 ButtonClickedEvent，存档界面出现
```

## 6.2 存档选择界面 → 选择存档

**已验证的按钮路径：**

| 元素 | 完整路径 |
|:----|:---------|
| 存档界面 | `Camera_UIRoot/Canvas/LayerPopUp/ViewRecordSelect` |
| 内容根节点 | `.../AnimationRoot/Content` |
| 子物体 | `Bg`、`Title`、`ScrollTypeToggleGroup`、`RecordHolder`、`ScrollRoot`、`CloseBtn` |
| 存档列表项 | `.../RecordHolder/RecordInfoItem`（第一个存档） |
| | `.../RecordHolder/RecordInfo_1` ~ `RecordInfo_4` |
| 继续按钮 | `.../{slot}/BtnHolder/ButtonContinue` |
| 回退按钮 | `.../{slot}/BtnHolder/ButtonRevertBack` |
| 删除按钮 | `.../{slot}/BtnHolder/ButtonDeleteBack` |
| 选中状态 | `.../{slot}` → `SwitchToggleSmall.isOn` = `true` 表示选中 |

> **核心机制：** 每个 `RecordInfo_X` 上挂载了 `PointClickBridge` 组件（实现 `IPointerClickHandler`），负责接收用户点击事件并驱动完整的"选中"逻辑。
>
> 关键知识点：
> - `SwitchToggleSmall` 只是视觉开关，**直接设置 `set_isOn(true)` 不会触发内部选中逻辑**，所以 `BtnHolder` 不会自动激活。
> - 正确的选中方式是通过 `simulate_click(game_object_path)` ——此工具使用 Unity 的 `EventSystem` 创建真实的 `PointerEventData`，通过 `ExecuteEvents.Execute` 触发 `IPointerClickHandler`，和真实鼠标点击完全一致。
> - `BtnHolder` 初始为 `active: false`，只有正确选中后才变为可见。
> - `RecordHolder` 上有 `CToggleGroup`，保证同时只有一个存档被选中（类似 RadioButton）。

### 查找存档名字

存档的名字在 `.../{slot}/NameBar/Renamer/Normal/Name` 的 `TextMeshProUGUI.text` 中。

```python
from ingame_helper import *

base = "Camera_UIRoot/Canvas/LayerPopUp/ViewRecordSelect/AnimationRoot/Content/RecordHolder"
slots = ["RecordInfoItem", "RecordInfo_1", "RecordInfo_2", "RecordInfo_3", "RecordInfo_4"]

# 列出所有存档槽位及其名字
for i, slot in enumerate(slots):
    r = query_component_field(
        game_object_path=f"{base}/{slot}/NameBar/Renamer/Normal/Name",
        component_type="Text", field="text")
    print(f"  {i}: {slot} → {r}")
```

**输出示例：**
```
0: RecordInfoItem → <color=#F8E6C1>太吾梦堂</color>
1: RecordInfo_1 → <color=#F8E6C1>测试用</color><color=#BDBDBD>(太吾梦堂)</color>
2: RecordInfo_2 → <color=#F8E6C1>太吾梦堂</color>
3: RecordInfo_3 → 空（无数据）
4: RecordInfo_4 → 空（无数据）
```

### 按名字选择存档并加载

> **核心原则：** 除非用户指定存档槽位，否则优先寻找名字包含"测试用"的存档加载，避免干扰正常存档。
>
> **关键修正：** 不要直接点击 `ButtonContinue`！`ButtonContinue` 加载的是**上一次选中的存档**（高亮状态），而非其父级 `RecordInfo` 的存档。
> 正确流程是：**先用 `simulate_click` 选中槽位（触发 `IPointerClickHandler`），再点击 `ButtonContinue`。**
>
> **陷阱：**
> - 不要使用 `SwitchToggleSmall.set_isOn(true)` 来选中——它只改视觉状态，不会驱动内部选中逻辑。
> - `SendMessage("OnPointerClick", null)` 会因 `PointerEventData` 为 null 而早期返回，也不生效。
> - 必须用 `simulate_click`（EventSystem + ExecuteEvents）模拟真实用户点击。

> **进入游戏后月报处理：** 存档加载成功后，游戏会自动弹出 **月报界面**（`ViewMonthNotify`），会挡住大部分 UI 操作。在执行其他操作前需要先关闭它。

```python
# 关闭月报（参考路径）
close_btn = "Camera_UIRoot/Canvas/LayerVeryTop/ViewMonthNotify/AnimRoot/Top/Close"
front_code(entry_name="UnityEngine.GameObject", chain=[
    {"step": "method", "name": "Find", "argTypes": ["System.String"], "args": [close_btn]},
    {"step": "method", "name": "GetComponent", "argTypes": ["System.String"], "args": ["UnityEngine.UI.Button"]},
    {"step": "property", "name": "onClick"},
    {"step": "method", "name": "Invoke"}
])
```

```python
import time, re
from ingame_helper import *

base = "Camera_UIRoot/Canvas/LayerPopUp/ViewRecordSelect/AnimationRoot/Content/RecordHolder"
slots = ["RecordInfoItem", "RecordInfo_1", "RecordInfo_2", "RecordInfo_3", "RecordInfo_4"]

# 1. 遍历所有存档槽位，找到名字包含"测试用"的
target_slot = None
for slot in slots:
    r = query_component_field(
        game_object_path=f"{base}/{slot}/NameBar/Renamer/Normal/Name",
        component_type="TextMeshProUGUI", field="text")
    if "测试用" in r:
        target_slot = slot
        print(f"找到测试用存档: {slot}")
        break

if not target_slot:
    target_slot = "RecordInfoItem"  # 没找到则用第一个
    print("未找到测试用存档，使用第一个")

# ── 2. 选中目标存档 ──────────────────────────────────────
# simulate_click 通过 EventSystem 创建 PointerEventData 并触发 IPointerClickHandler
# 与真实鼠标点击行为完全一致
r = simulate_click(game_object_path=f"{base}/{target_slot}")
print("选中结果:", r[:100])  # → {"success": true, "target": "RecordInfo_1", "executed": 2}

time.sleep(0.5)

# ── 3. 点击 ButtonContinue ──────────────────────────────
r = front_code(entry_name="UnityEngine.GameObject", chain=[
    {"step": "method", "name": "Find", "argTypes": ["System.String"],
     "args": [f"{base}/{target_slot}/BtnHolder/ButtonContinue"]},
    {"step": "method", "name": "GetComponent", "argTypes": ["System.String"],
     "args": ["UnityEngine.UI.Button"]},
    {"step": "property", "name": "onClick"},
    {"step": "method", "name": "Invoke"}
])
print(r)  # → {"_type": "ButtonClickedEvent"}

# 4. 等待加载（约 5~20 秒）
for _ in range(30):
    time.sleep(1)
    try:
        r = query_world_info()
        if r and "currDate" in str(r) and int(re.search(r'"currDate":\s*(\d+)', str(r)).group(1)) > 0:
            print("进入游戏成功:", r[:80])
            break
    except:
        pass
```

    {"step": "method", "name": "Find", "argTypes": ["System.String"],
     "args": ["Camera_UIRoot/Canvas/LayerVeryTop/ViewDialog/AnimRoot/Buttons/BtnYes"]},
    {"step": "method", "name": "GetComponent<UnityEngine.UI.Button>"},
    {"step": "property", "name": "onClick"},

        pass

## 6.8 商店购物

> 在商店界面筛选商品并通过 `shop_buy_filtered` 批量加入交换列表，再确认交易。

**商品筛选参数：**

每个 filter 条件之间是与(AND)关系，多个 filter 之间是或(OR)关系。

| 参数 | 类型 | 说明 | 示例 |
|:----|:----|:-----|:-----|
| `itemType` | int | 物品类型（5=材料, 7=食物, 6=工具, 4=载具） | `{"itemType": 5}` |
| `minGrade` | int | 最低品级（含），品级 0=9品，9=1品 | `{"minGrade": 7}` |
| `maxGrade` | int | 最高品级（含） | `{"maxGrade": 9}` |
| `name` | string | 商品名模糊匹配 | `{"name": "香菇"}` |
| `amount` | int | 购买数量（不传则全量） | `{"amount": 2}` |
| `pricePercent` | int | 涨跌价（<0=降价，>0=涨价，0=原价） | `{"pricePercent": -1}` |

**已验证的路径：**

| 元素 | 完整路径 |
|:----|:---------|
| 商店界面 | `Camera_UIRoot/Canvas/LayerPopUp/ViewShop` |
| 确认按钮 | `.../ViewShop/Root/MiddleContent/Confirm` |
| 二次确认弹窗 | `Camera_UIRoot/Canvas/LayerPopUp/UI_ShopConfirm/Popup3/Popup3` |
| 二次确认按钮 | `.../Popup3/Confirm` |
| 取消按钮 | `.../Popup3/Cancel` |
| 错误提示文字 | `.../UI_ShopConfirm/.../Center/ConfirmContent`（显示如"没有足够的银钱"） |

### 通用筛选参数

```python
import time, json
from ingame_helper import *

base = "Camera_UIRoot/Canvas/LayerPopUp/ViewShop"

# 0. 清空交换列表（如需）
r = front_code(entry_name="UnityEngine.GameObject", chain=[
    {"step": "method", "name": "Find", "argTypes": ["System.String"], "args": [base]},
    {"step": "method", "name": "GetComponent", "argTypes": ["System.String"], "args": ["ViewShop"]},
    {"step": "method", "name": "ResetTarget"}
])
time.sleep(1)

# 1. 筛选商品并加入交换列表
#   filters 条件之间是 OR 关系：满足任一 filter 即加入
r = shop_buy_filtered(filters=[
    {"name": "香菇", "amount": 1},   # 具体商品 + 限购
    {"itemType": 5, "pricePercent": -1, "maxGrade": 2},  # 降价低品材料
])
j = json.loads(r)
print(f"总 {j['totalItems']} 商品，加入 {j['added']} 种")

# 2. 检查能否购买（Confirm 按钮的 interactable）
r = query_component_info(game_object_path=f"{base}/Root/MiddleContent/Confirm",
    component_type="CButton")
j = json.loads(r)
if j[0]['fields']['interactable']:
    print("资金充足，可继续交易")
else:
    print("资金不足，Confirm 按钮为灰色")
```
