# 脚本查询工作流总结

## 任务目标
编写一个 C# 脚本 (`cooking.cs`)，通过 `back_cs` 在游戏后端执行，实现三轮测试：
1. 无参数 → 获取当前地图所有角色的技艺数据
2. `byId` → 按 charId 查指定角色
3. `byName` → 按显示名查指定角色

输出 CSV 格式到 `forMod/` 目录。

## 最终结果

### cooking.cs 核心结构

```csharp
// 模式1(无参数): 当前地图所有角色 charId,显示名,身份,格子id,资质,造诣(CSV)
// 模式2(byId): 按 charId 查
// 模式3(byName): 按显示名查
// 参数 skillType: 技艺索引 0-15, 默认14(厨艺)
//  0=音律,1=弈棋,2=诗书,3=绘画,4=术数,5=品鉴,6=锻造,7=木工,8=医术,9=毒术,10=织锦,11=巧匠,12=道法,13=佛法,14=厨艺,15=杂学

var cd = GameData.Domains.DomainManager.Character;
var md = GameData.Domains.DomainManager.Map;
int skillType = Params.ContainsKey("skillType") ? int.Parse(Params["skillType"].ToString()) : 14;
```

### 三个入口模式

| 模式 | globals | 说明 |
|------|---------|------|
| `all` | 不传或 `mode=all` | 获取太吾所在 Area 全部区块的所有角色 |
| `byId` | `mode=byId, charId=6755, skillType=8` | 指定角色ID |
| `byName` | `mode=byName, name=太吾梦堂, skillType=6` | 按显示名精确匹配 |

## 关键技术点

### 1. 后端可用 API

#### 获取显示名
```csharp
// CharacterDomain.GetMonasticTitleOrDisplayName(int charId)
// 返回 ValueTuple<string, string>(surname, givenName)
var rn = HarmonyLib.Traverse.Create(cd)
    .Method("GetMonasticTitleOrDisplayName", new object[] { charId }).GetValue();
var rt = HarmonyLib.Traverse.Create(rn);
string name = (rt.Field("Item1").GetValue()?.ToString() ?? "") 
            + (rt.Field("Item2").GetValue()?.ToString() ?? "");
```
- 太吾: `太吾梦堂`
- 普通角色: `耿星璧`（纯姓名，无称号）

#### 获取身份
```csharp
// 从 _organizationInfo 字段获取
var orgInfo = HarmonyLib.Traverse.Create(c).Field("_organizationInfo").GetValue();
// ToString 结果: "市镇大夫", "太吾村太吾传人"
```

#### 获取技艺资质
```csharp
// _baseLifeSkillQualifications: LifeSkillShorts, 索引器 int Get(int index)
var ls = HarmonyLib.Traverse.Create(c).Field("_baseLifeSkillQualifications").GetValue();
int qual = (short)HarmonyLib.Traverse.Create(ls).Method("Get", new object[] { (sbyte)skillType }).GetValue();
```

#### 获取技艺造诣
```csharp
// Character.GetLifeSkillAttainment(sbyte type) 方法
var mi = charObj.GetType().GetMethod("GetLifeSkillAttainment", new Type[] { typeof(sbyte) });
int att = (short)mi.Invoke(charObj, new object[] { (sbyte)skillType });
```

#### 获取格子和位置
```csharp
// _location 字段: Location 结构体，含 AreaId(short) + BlockId(short)
var loc = HarmonyLib.Traverse.Create(c).Field("_location").GetValue();
short areaId = HarmonyLib.Traverse.Create(loc).Field("AreaId").GetValue<short>();
short blockId = HarmonyLib.Traverse.Create(loc).Field("BlockId").GetValue<short>();
```

### 2. 地图角色遍历

```csharp
// 用 TryGetBlock 安全遍历区块 (GetBlock 对不存在区块抛异常)
for (short b = 0; b < 700; b++) {
    GameData.Domains.Map.MapBlockData blk;
    if (!md.TryGetBlock(new GameData.Domains.Map.Location(areaId, b), out blk)) continue;
    if (blk == null) continue;
    if (blk.CharacterSet != null) { foreach (var id in blk.CharacterSet) allIds.Add(id); }
    if (blk.FixedCharacterSet != null) { foreach (var id in blk.FixedCharacterSet) allIds.Add(id); }
    if (blk.EnemyCharacterSet != null) { foreach (var id in blk.EnemyCharacterSet) allIds.Add(id); }
    if (blk.InfectedCharacterSet != null) { foreach (var id in blk.InfectedCharacterSet) allIds.Add(id); }
}
```
- 注：玩家太吾不在区块的 CharacterSet 中，不额外加

### 3. 从姓名反查 ID

```csharp
// 遍历 characterDomain._objects 字典，比对 GetMonasticTitleOrDisplayName 结果
var obj = HarmonyLib.Traverse.Create(cd).Field("_objects").GetValue();
var dict = obj as System.Collections.IDictionary;
foreach (var k in dict.Keys) {
    int id = (int)k;
    var c = HarmonyLib.Traverse.Create(cd).Method("GetElement_Objects", new object[] { id }).GetValue();
    if (c == null) continue;
    if (GetDispName(id) == target) { found = id; break; }
}
```

### 4. 脚本文件方式

脚本保存在独立 `.cs` 文件（如 `cooking.cs`），通过 `codeFile` 参数引用：
```json
{
  "type": "back_cs",
  "params": {
    "codeFile": "C:/path/to/cooking.cs",
    "globals": {"mode": "byId", "charId": 6755, "skillType": 8}
  }
}
```

## 调试提示

- 后端日志路径: `C:\Program Files (x86)\Steam\steamapps\common\The Scroll Of Taiwu\Logs\GameData_*.log`
- 注意 `GetBlock` 对不存在的区块抛异常，必须用 `TryGetBlock`
- 不要用 `_lifeSkillQualifications`（计算值可能为0），用 `_baseLifeSkillQualifications`（存储值）
- `LifeSkillShorts` 是 FixedBuffer 结构体，通过 `Get(int)` 方法访问
- `MapBlockData` 是 class（不是 struct），字段为 public field 可直接访问
- `_objects` 是 CharacterDomain 中的 IDictionary，key=`int`(charId), value=`Character`
