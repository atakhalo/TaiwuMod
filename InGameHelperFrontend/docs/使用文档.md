# InGameHelper — 游戏内信息桥接工具

## 概述

InGameHelper 是一个为《太吾绘卷》设计的 Mod，通过**文件通讯**的方式，为外部程序（如 AI Agent）提供游戏内信息查询能力。

### 功能

- **场景查询** — 查询 Unity 场景中的 GameObject 层级、组件信息、组件字段值
- **游戏数据查询** — 查询游戏数据域（角色、太吾、世界、物品等）的任意信息
- **统一文件接口** — 外部程序只需读写 `quest.json` / `result.json`，无需关心内部实现

## 架构

```
外部程序 (AI Agent)
  │  写入 quest.json  │  读取 result.json
  ▼                   ▲
┌────────────────────────────────────────────┐
│  InGameHelperFrontend (前端插件)            │
│  ├─ FileSystemWatcher → 监听 quest.json    │
│  ├─ 场景请求 → Unity API 处理              │
│  ├─ 数据请求 → 写入 _backend_quest.json    │
│  └─ FileSystemWatcher → 监听 _backend_result.json → 转发到 result.json
└────────────────────────────────────────────┘
                          │
                          │  文件通讯
                          ▼
┌────────────────────────────────────────────┐
│  InGameHelperBackend (后端插件)             │
│  ├─ FileSystemWatcher → 监听 _backend_quest.json
│  ├─ DomainManager + Traverse 查询游戏数据  │
│  └─ 写入 _backend_result.json              │
└────────────────────────────────────────────┘
```

### 组件说明

| 组件 | 运行环境 | 职责 |
|------|---------|------|
| `InGameHelperFrontend.dll` | Unity 前端（Assembly-CSharp） | 文件监听、场景GameObject查询 |
| `InGameHelperBackend.dll` | 游戏后端（GameData） | 游戏数据域查询 |

> **注意**：前端和后端运行在不同的 .NET 运行时中，通过文件系统进行通信，不能直接反射调用。

## 配置

### config.xml

```xml
<?xml version="1.0" encoding="utf-8"?>
<config>
    <!-- 工作目录：所有通讯文件都在此目录下 -->
    <workDir>C:\path\to\work\dir</workDir>
    <!-- 外部请求文件名（外部程序写入） -->
    <quest>quest.json</quest>
    <!-- 外部响应文件名（外部程序读取） -->
    <result>result.json</result>
    <!-- 结果索引文件名 -->
    <resultIndex>result_index.json</resultIndex>
    <!-- 后端请求文件（前端→后端，内部使用） -->
    <backendQuest>_backend_quest.json</backendQuest>
    <!-- 后端结果文件（后端→前端，内部使用） -->
    <backendResult>_backend_result.json</backendResult>
</config>
```

## 通讯协议

### 请求格式

外部程序写入 `quest.json`：

```json
{
    "requestId": "唯一请求标识（如 UUID 或时间戳）",
    "type": "请求类型",
    "params": {}
}
```

### 响应格式

前端/后端写入 `result.json`：

```json
{
    "requestId": "对应请求的标识",
    "success": true,
    "data": {},
    "error": null,
    "hasLongResult": false,
    "longResultFile": null
}
```

- `hasLongResult`: 当结果超过10KB时设为 `true`，数据写入独立文件
- `longResultFile`: 长结果文件的名称，在同一工作目录下
